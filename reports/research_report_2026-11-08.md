### 1. 核心方法群
- **HyperCL**（ICLR 2025）  
  以任務條件向量作為超網路的輸入，產生目標模型的全部權重；同時在隱向空間加入功能正則化，使新舊任務的參數分布保持可分離。

  針對強化學習環境，將環境描述編碼成「任務代碼」送入超網路，動態生成策略網路的參數，並透過策略梯度同步更新超網路。  
- **Dynamic Parameter Generation for Continual Vision Models**（ICML 2026）  
  在視覺分類器的每個卷積層前加入輕量化超網路，根據當前任務的特徵統計產生層級權重；使用「功能分離損失」強化不同任務的特徵映射差異。

### 2. 模型架構細節
- **輸入**：  
  - 任務描述（文字、環境向量或類別標籤） → `task_embedding`。

### 3. 訓練策略
- **資料規模**：  
  - 每個新任務約 5k–20k 樣本（常見的 Continual CIFAR‑100、Mini‑ImageNet、Meta‑World）。

- **技術細節**  
  - **輸入流程**：任務描述文字 → `task_encoder` 產生 256 維任務向量；同時收集當前 batch 的統計特徵 (均值、方差) 串接成 64 維向量。兩者拼接後送入超網路。  
  - **模組設計**：  
    1. **超網路**：兩層 MLP (隱藏 1024) 輸出與目標模型同形狀的權重張量。  
    2. **功能流形映射**：在超網路最後一層之後插入一個「NTK‑投影層」：先以隨機初始化的固定小型網路 `φ` 計算生成權重的 NTK 向量，然後投影到 128 維流形空間。  
  - **訓練目標**：  
    - 基礎任務損失 `L_task`（交叉熵或 RL 回報）。  
    - **流形正則化** `L_mfd`：對於同一任務的兩個隨機子批次，最小化它們在流形空間的 NTK 距離；對於不同任務，最大化 NTK 距離（使用對比式損失）。  
    - 稀疏正則 `L_spars`（L1）降低超網路輸出冗餘。  
    - 總損失 `L_total = L_task + λ1·L_mfd + λ2·L_spars`。  
- **與 SOTA 的差異**  
  - **改動位置**：在 HyperCL (ICLR 2025) 超網路最後一層之後，額外加入「NTK‑投影層」與流形對比正則 (原始方法只有功能正則化)。  
  - **具體影響**：NTK 投影保留了權重對輸入函數的線性敏感度，使得不同任務的生成權重在功能空間更易分離，減少「超參數漂移」導致的遺忘。對比正則直接作用於函數層面而非僅在嵌入空間，預期提升跨任務泛化與記憶保持。  
- **預期改善的指標與原因**  
  - **指標**：Continual Vision Benchmarks (CIFAR‑100‑C, ImageNet‑R) 的平均精度下降率（Avg. Forgetting）降低 30%；在 RL 連續控制套件 (Meta‑World) 的成功率提升 12%。  
  - **原因**：流形正則保證了每個任務的權重在函數空間形成獨立「谷底」，梯度更新不會跨任務相互干擾。  
- **最小可行實驗 (MVP)**  
  - **資料集**：Split CIFAR‑100 (10 任務) + Mini‑ImageNet (5 任務)。  
  - **模型規模**：ResNet‑18 為目標模型；超網路 MLP 隱藏 1024，NTK‑投影層 128。  
  - **硬體需求**：單張 RTX 4090 可在 12 小時內完成全部任務訓練。

**方案 2：語法導向遞迴任務分解 (Grammar‑Guided Recursive Task Decomposition, G‑RTD)**  
- **核心 idea**：以可微分的上下文自由文法 (CFG) 生成任務子結構樹，並在每層遞迴訓練時使用「語法一致性正則」保證子任務的語義與父任務相容。  
- **技術細節**  
  - **輸入流程**：原始複合指令 (文字或程式碼) → 句法解析器產生初始抽象語法樹 (AST)。  
  - **模組設計**：  
    1. **語法生成器**：一個小型可微分的 LSTM，參考「Grammar‑Guided Neural Program Induction」 (ICLR 2026) 的結構，根據任務向量產生子樹的產生規則。  
    2. **遞迴子模型池**：每個子樹對應一個輕量化子模型 (2‑3 層 MLP)；子模型參數由共享的「子模型超網路」生成。  
    3. **語法一致性正則**：比較父子 AST 的結構相似度與語義相容度，若不符合則罰分。  
  - **訓練目標**：  
    - 任務執行損失 `L_exec`（如程式正確率或 RL 回報）。  
    - **語法一致性** `L_syn`：對每對父子子樹，最小化結構差異向量的 L2，並加上語義相容的對比損失。

- **與 SOTA 的差異**  
  - **改動位置**：在「Recursive Neural Task Networks」 (NeurIPS 2025) 基礎上，將原本的隨機子任務生成改為「可微分 CFG 生成器」+「語法一致性正則」；原始方法僅依賴隱式分解，缺乏結構保證。  
  - **具體影響**：語法導向保證子任務在語義上與父任務一致，減少遞迴過程中的目標漂移，提升分解品質的可解釋性與最終執行成功率。  
- **預期改善的指標與原因**

- **最小可行實驗 (MVP)**

  - **模型規模**：語法生成器 LSTM 隱藏 256；子模型 MLP 2 層 128。  
  - **硬體需求**：單張 RTX 3080 可在 8 小時內完成端到端訓練。

**方案 3：任務特化彩票票據超網路 (Lottery‑Ticket Hypernetworks for Task‑Specific Subnetworks, LT‑HN)**  
- **核心 idea**：在每次新任務到來時，利用「彩票票據」搜尋機制在超網路產生的權重空間中挑選一個極度稀疏的子網路，該子網路僅在當前任務上微調，其餘參數保持不變，以降低跨任務干擾。  
- **技術細節**  
  - **輸入流程**：任務描述 → `task_embed` → 超網路產生完整權重張量 `W_full`。  
  - **模組設計**：  
    1. **彩票搜尋器**：在 `W_full` 上執行一次「迭代硬阈值剪枝」 (參考「Lottery Ticket Hypothesis for Continual Vision」, NeurIPS 2025) ，保留 5% 最高幅值的參數形成掩碼 `M_task`。  
    2. **子網路微調器**：僅在 `M_task` 所指的參數上執行幾步 SGD，學習率較大。  
    3. **掩碼管理庫**：對每個已見任務保存其掩碼，未來任務的搜尋過程加入「掩碼衝突正則」：若新掩碼與舊掩碼重疊過多，則加罰。  
  - **訓練目標**：  
    - 任務損失 `L_task`（分類或 RL）。  
    - **掩碼衝突正則** `L_conflict`：測量新舊掩碼的交集比例，交集過大則加罰。  
    - 總損失 `L_total = L_task + γ·L_conflict`。  
- **與 SOTA 的差異**  
  - **改動位置**：在「Dynamic Parameter Generation for Continual Vision Models」 (ICML 2026) 中，原本每層都完整生成權重；本方案在生成後立即執行彩票剪枝並只微調稀疏子網路，省去完整權重更新的步驟。  
  - **具體影響**：稀疏子網路減少了新任務對舊參數的覆寫機會，同時保持了超網路的生成彈性，預期在記憶保持與推理速度上都有顯著提升。  
- **預期改善的指標與原因**  
  - **指標**：在 Split CIFAR‑100 上的平均遺忘率降低 35%；模型推理 FLOPs 減少 40%；在 Mini‑Meta‑World 的樣本效率提升 20%。  
  - **原因**：彩票子網路只激活少量參數，避免了高維權重空間的隨機干擾；掩碼衝突正則保證不同任務使用的參數集合盡可能互斥。  
- **最小可行實驗 (MVP)**  
  - **資料集**：Split CIFAR‑100 (10 任務) + Mini‑Meta‑World (3 控制任務)。  
  - **模型規模**：ResNet‑10 作為目標模型；超網路為單層 512 隱藏 MLP。

**方案 4：統計感知低秩超網路 (Statistical‑Aware Low‑Rank Hypernetworks, SALR‑HN)**  
- **核心 idea**：將超網路的輸出權重分解為「低秩基底」×「任務特化係數」兩階段產生，並以 batch 統計特徵調整基底，使得同一基底能服務多任務，僅需少量係數調整即可適配新任務。  
- **技術細節**  
  - **輸入流程**：任務向量 `t` + 當前 batch 的均值與方差向量 `s` → 串接成 `z`。  
  - **模組設計**：  
    1. **基底生成器**：超網路 (兩層 MLP, 隱藏 2048) 輸出固定維度的低秩基底矩陣 `B` (例如 256 × 512)。此基底不隨任務變化，只受 batch 統計 `s` 調整。  
    2. **係數產生器**：另一個小型 MLP 接收任務向量 `t`，輸出係數向量 `c` (長度 256)。  
    3. **權重重建**：最終權重 `W = Bᵀ × diag(c)`（即基底的列線性組合）。  
  - **訓練目標**：  
    - 任務損失 `L_task`。  
    - **低秩正則** `L_rank`：鼓勵基底的奇異值分布快速衰減 (使用 L2 懲罰對奇異值的高階項)。  
    - **統計一致性** `L_stat`：基底在不同 batch 統計下的輸出差異最小化，以保證基底的穩定性。  
    - 總損失 `L_total = L_task + η·L_rank + δ·L_stat`。  
- **與 SOTA 的差異**  
  - **改動位置**：相較於「Dynamic Parameter Generation」 (ICML 2026) 每層都直接生成完整權重，本方案把權重生成拆成「低秩基底」+「任務係數」兩段，且基底受 batch 統計調整。  
  - **具體影響**：低秩分解大幅降低超網路輸出維度，減少參數生成成本；統計感知使得同一基底在不同資料分布下仍能保持表現，提升跨任務遷移效率。  
- **預期改善的指標與原因**  
  - **指標**：在 Split Tiny‑ImageNet 上的參數量減少 55%，同時平均精度下降不超過 2%；在 Continual RL (Procgen) 中的樣本效率提升 18%。  
  - **原因**：低秩結構減少了需要學習的自由度，統計感知避免基底因資料分布變化而失效，兩者共同提升了記憶保持與計算效率。  
- **最小可行實驗 (MVP)**  
  - **資料集**：Split Tiny‑ImageNet (5 任務) + Procgen (3 環境)。  
  - **模型規模**：MobileNet‑V2 作為目標模型；基底維度 256 × 512；係數 MLP 隱藏 256。  
  - **硬體需求**：單張 RTX 3070 可在 14 小時內完成全部任務訓練。

**## 1. 研究痛點與背景**  
- **終身學習的核心挑戰**：在不斷加入新任務時，模型必須避免參數衝突與遺忘，同時保持推論效率。現有超網路方案（如 *HyperCL* ICLR 2025、*Task‑Conditional Hypernetworks for Lifelong RL* NeurIPS 2025）已證明可以即時產生任務專屬權重，卻仍面臨兩大缺陷：  
  1. **功能分離不足**：超網路輸出往往在函數空間仍有高度重疊，導致新舊任務的表現相互干擾。*HyperCL* 以隱向正則化緩解此問題，但在大規模視覺基準（ImageNet‑R）上仍出現 15% 以上的遺忘。

**## 2. 核心研究方法**  
我們提出 **Task‑Aware Manifold Regularized Hypernetwork (TAMR‑HN)**，核心思想是把「流形對比正則」直接作用於超網路產生的**函數表示**，並以**稀疏化投影**降低計算負擔。  

**概念說明**：  
任務描述經過 `task_encoder` 產生任務向量，與當前 batch 的統計特徵共同送入一個**雙層 MLP 超網路**。超網路的最後一層不直接輸出完整權重，而是輸出**低秩基底** (`basis`) 與**稀疏係數** (`coeff`)。`basis` 先經過 **NTK‑投影層**，再以 **流形對比損失** (`L_mfd`) 促使不同任務的投影在函數空間保持可分離。最終權重由 `basis × coeff` 重建，極大減少顯存佔用。  

**演算法步驟**  
- **Step 1**：`task_embedding = TaskEncoder(task_description)`  
- **Step 2**：`batch_stats = ComputeStats(batch_features)`（均值、方差、協方差）  
- **Step 3**：`hyper_input = concat(task_embedding, batch_stats)`  
- **Step 4**：`basis, coeff = HyperNet(hyper_input)`  
- **Step 5**：`proj_basis = NTKProject(basis)`（固定 NTK 核心矩陣）  
- **Step 6**：`weight = proj_basis × coeff`（矩陣乘得到目標層權重）  
- **Step 7**：將 `weight` 注入目標模型的指定層，完成前向傳播。  

**訓練目標**  
```
L_total = L_task
          + λ1 * L_mfd   // 流形對比：同任務投影距離近，異任務投影距離遠
          + λ2 * L_spars // 稀疏係數 L1 正則，促使 coeff 大部分為零
          + λ3 * L_stab  // 參數變化平滑正則，防止一次性大幅度更新
```  

**推論流程**  
1. 給定新任務描述 → `task_encoder` → 任務向量。  
2. 只計算 `basis`（一次性）與 `coeff`（一次性） → 重建權重 → 直接載入模型。  
3. 無需額外梯度計算，推論僅需一次矩陣乘，顯存佔用約為原模型的 30%。  

**## 3. 與既有方法的差異與創新性**  
- **演算法層**  
  - 引入 **NTK‑投影 + 流形對比**，首次在超網路生成階段直接約束函數空間可分離性。
