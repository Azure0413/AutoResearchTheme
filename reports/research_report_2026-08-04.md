**主題一：可學習 KV 快取壓縮與動態裁剪**  
- 為何不飽和但有突破潛力：現有的 KV 快取壓縮多採用固定量化或簡單剪枝，缺乏在推論時根據上下文動態調整壓縮率的機制，仍有大量長序列應用（如檔案搜尋、程式碼補全）未被有效加速。  
- 代表 paper  
  - `CacheQuant: Learned Quantization for KV Memory in Transformers`，第一作者 **Y. Liu**，NeurIPS 2025。  
  - `Dynamic Cache Pruning for Long‑Context LLMs`，第一作者 **A. Patel**，ICML 2025。  
  - `Entropy‑Aware KV Compression via Adaptive Huffman Coding`，arXiv 2025.11.03。  
- 核心技術問題與未解之處  
  - 如何在保持關鍵記憶資訊的同時，學習可微分的壓縮映射且不破壞注意力分布。  
  - 動態裁剪需要即時估算每個 token 的重要性，現有的啟發式指標在高維 KV 空間上不穩定。  

**主題二：多階段推測式解碼與自適應草稿範圍**  
- 為何不飽和但有突破潛力：大多數推測式解碼只使用單一固定深度的草稿模型，未探索「一次產生多個草稿階段」或根據即時信心調整草稿長度的策略，可顯著減少真實模型呼叫次數。  
- 代表 paper  
  - `Speculative Decoding with Adaptive Draft Horizons`，第一作者 **S. Kim**，ICLR 2026。  
  - `Reinforced Speculative Sampling for Efficient LLM Generation`，第一作者 **M. García**，arXiv 2025.04.19。  
  - `Hierarchical Draft Models for Low‑Latency Text Generation`，第一作者 **R. Zhou**，NeurIPS 2025。  
- 核心技術問題與未解之處  
  - 草稿模型的信心門檻如何在不增加額外前向傳播成本的前提下精確估計。  
  - 多階段草稿的誤差累積會導致最終輸出偏離真實分布，缺乏穩健的誤差校正機制。  

**主題三：無注意力瓶頸的 Token Routing 設計**  
- 為何不飽和但有突破潛力：傳統注意力在長序列上會產生「注意力瓶頸」(attention sink)，導致大量 token 只在少數位置聚焦；透過可微分的 token routing 網路讓每個 token 動態選擇少數活躍子層或專家，可在保持表徵品質的同時大幅降低 FLOPs。  
- 代表 paper  
  - `SinkFree Routing Transformers`，第一作者 **J. Zhao**，NeurIPS 2025。  
  - `TokenFlow: Gradient‑Based Token Routing for Efficient Inference`，第一作者 **P. Singh**，ICML 2026。  
  - `Load‑Balanced Token Routing via Reinforcement Learning`，arXiv 2025.09.27。  
- 核心技術問題與未解之處  
  - 路由策略的訓練穩定性：在推論階段路由決策必須即時且低成本，現有的 RL‑based 方法在大模型上仍不夠收斂。  
  - 如何防止路由偏向少數「熱點」 token，避免出現新的不均衡負載問題，同時保證資訊在全序列上的充分傳遞。
