### 1. 核心方法群
- **Subgraph Replay (SR)**：在每次新任務訓練前，從先前任務的圖中抽取具代表性的子圖，利用圖同構或結構相似度作為抽樣指標，將這些子圖作為回放樣本，防止舊任務的結構資訊被遺忘。  
- **Hierarchical Memory Bank (HMB)**：將回放子圖依照抽象層級分層存放，低層保存局部結構（如三角形、四節點子圖），高層保存全局模式（如社群結構），在前向傳播時根據當前任務的結構相似度動態選擇相應層級的記憶。  
- **Adaptive Subgraph Selector (ASS)**：使用可微分的子圖選擇器（如 Gumbel‑Softmax 采樣）根據當前任務的梯度訊號調整子圖抽樣分布，使回放子圖更貼合新任務的關鍵結構，兼顧舊任務保留與新任務適應。

---

### 2. 模型架構細節
- **輸入**：一批圖 `G = {V, E}`，每個節點有特徵向量 `x_v`，邊可能帶有權重。  
- **輸出**：任務特定的預測（節點分類、圖分類或連邊預測），同時產生一組「記憶向量」供回放使用。  
- **關鍵模組**  
  - `GNN Encoder`（多層 GraphSAGE 或 GAT），產生節點嵌入。  
  - `Subgraph Pooler`：根據 `ASS` 產生的子圖掩碼，聚合子圖嵌入形成子圖表徵。  
  - `Hierarchical Memory Bank`：由多層 `MemorySlot` 組成，每層保存固定數量的子圖表徵與對應的圖結構資訊。  
  - `Task Decoder`：根據當前任務類型（分類/回歸）使用線性層或 MLP 輸出結果。  
- **訓練目標**  
  - 主任務損失 `L_task`（交叉熵或 MSE）。  
  - 記憶一致性損失 `L_mem`：使回放子圖的嵌入在新舊任務間保持相似（如對比損失）。  
  - 子圖選擇正則化 `L_sel`：鼓勵子圖稀疏且多樣（如熵正則化）。

---

### 3. 訓練策略
- **資料規模**：每個任務使用 1,000–5,000 個圖（常見圖分類資料集），子圖回放數量固定為 200–500 個。  
- **Batch size**：圖批次大小 32，子圖回放批次大小 64（可在同一 GPU 上同時載入）。  
- **優化器**：AdamW，學習率 1e-3，權重衰減 1e-4。對 `ASS` 使用較低的學習率 5e-4，以穩定可微分抽樣。  
- **Loss 設計**：`L_total = L_task + λ1 * L_mem + λ2 * L_sel`，其中 `λ1≈0.5`、`λ2≈0.1` 為常用超參。  
- **實作 tricks**  
  - 使用 `torch_geometric` 的 `NeighborSampler` 進行子圖抽樣，減少記憶庫建構時間。  
  - 記憶庫更新採用 **FIFO + 優先級**：新抽出的子圖若在結構相似度上超過門檻則覆蓋最舊的低優先級條目。  
  - 在每個 epoch 結束時執行一次 **記憶蒸餾**：用舊模型的 logits 作為軟目標，提升回放穩定性。  

---

### 4. 主要 benchmark 與資料集
- **OGB‑MolPCBA**（分子圖多任務分類）：測量平均 ROC‑AUC。  
- **ZINC**（圖回歸任務）：測量 MAE。  
- **Cora / PubMed**（節點分類持續學習）：測量整體準確率與遺忘率（前任務 ACC 下降幅度）。

### 5. 方法優劣比較
- **Subgraph Replay (SR)**
  - 優點  
    - 只回放關鍵結構，記憶需求遠低於全圖回放。  
    - 子圖抽樣可直接利用圖同構工具，實作簡單。  
  - 缺點  
    - 子圖選擇過於靜態，無法適應新任務的結構變化。  
    - 若子圖過小，可能失去全局資訊，導致舊任務性能急劇下降。  

- **Hierarchical Memory Bank (HMB)**
  - 優點  
    - 多層記憶提供不同尺度的結構資訊，對抗遺忘更全面。  
    - 可根據任務相似度動態調整層級取樣，提高回放效率。
