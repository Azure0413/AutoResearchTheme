**## 1. 研究痛點與背景**  
- 現有的 **圖結構好奇心探索**（如《Graph Curiosity: Structured Exploration via Graph Neural Networks》NeurIPS 2025）僅在單層資訊增益上給予內在獎勵，當圖的拓撲在長時間內變化不大（例如固定的分子結構）時，資訊增益趨於零，探索信號失效。  
- **無獎勵世界模型**（《Self‑Supervised World Models for Reward‑Free Reinforcement Learning》ICLR 2026）在高維觀測下容易過度擬合噪聲，導致探索多樣性下降，且缺乏對觀測噪聲的顯式估計。  
- 兩者皆未同時考慮 **圖結構的層次化變化** 與 **觀測噪聲的自適應加權**，在動態關聯式環境（化學合成流程、網路路由）中難以取得穩定且高效的探索行為。  

**關鍵缺口**：缺少一套能在 **動態圖環境** 中，同時利用 **層次化資訊增益** 與 **噪聲感知預測誤差** 產生內在獎勵的框架，且計算成本必須能在單張 24‑48 GB GPU 上跑完 1 M 步。

**## 2. 核心研究方法**  
本研究提出 **層次化噪聲感知圖好奇心框架**（Hierarchical Noise‑Aware Graph Curiosity, **HNAGC**），結合圖神經網路、動態子圖聚類與噪聲估計的自監督世界模型，產生兼具局部與全局、且對噪聲自適應的內在獎勵。  

**演算法流程**  
1. **觀測編碼**：使用 `Encoder_GNN` 把當前圖 `G_t`（節點特徵 `x_v`、邊特徵 `e_uv`）映射到節點隱向 `h_v^t`。  
2. **動態子圖聚類**：在隱向空間以 **Leiden 社群偵測** 產生子圖集合 `C_t = {c_1,…,c_K}`，子圖數量 `K` 依圖密度自適應。  
3. **噪聲估計**：`NoiseNet` 接收 `h_v^t` 輸出每個節點的觀測噪聲方差 `σ_v^t²`。  
4. **局部好奇心**：計算每個節點的 **變異係數** `CV_v = std(h_v^{t+Δ}) / mean(h_v^{t+Δ})`，取平均得到 `Curiosity_Local = mean(CV_v)`.  
5. **全局好奇心**：對每個子圖聚合隱向 `g_k^t = mean_{v∈c_k}(h_v^t)`，以 **高斯近似** 計算跨步 KL 散度 `KL(g_k^{t+Δ} || g_k^t)`，再取平均得到 `Curiosity_Global`.  
6. **噪聲加權預測誤差**：使用 `Transition`（小型 Transformer）預測下一步隱向 `\hat{z}_{t+1}`，計算 **噪聲加權均方誤差** `PE = mean( ( \hat{z}_{t+1} - z_{t+1} )² / σ_t² )`.  
7. **內在獎勵組合**：  
   `r_int = α·Curiosity_Local + β·Curiosity_Global + γ·PE`，其中 `α,β,γ` 隨訓練進度逐步衰減，以避免早期過度依賴單一信號。  
8. **策略更新**：使用 **PPO** 或 **SAC** 以 `r_int` 為唯一獎勵，執行離線策略梯度更新。  

**訓練目標**  
- 重建損失 `L_recon`（可選 Decoder）  
- 預測損失 `L_pred = PE`  
- 內在獎勵最大化 `L_int = - r_int`（負號因 PPO 需要最小化）  
- 總損失 `L_total = λ_recon·L_recon + λ_pred·L_pred + λ_int·L_int`，超參數在 0.1‑1 之間調整。  

**推論流程**  
1. 給定當前圖 `G_t`，快速跑 `Encoder_GNN` → `h_v^t`。  
2. 直接計算 `Curiosity_Local`、`Curiosity_Global`、`PE`，得到 `r_int`。  
3. 依據已訓練的策略網路輸出行動 `a_t`。  
整個推論僅需一次 GNN 前向與一次小型 Transformer 前向，記憶體占用 < 8 GB。

**## 3. 與既有方法的差異與創新性**  
- **演算法層**  
  - 同時結合 **層次化資訊增益**（局部變異係數 + 全局 KL 散度）與 **噪聲加權預測誤差**，在單一內在獎勵中兼顧結構變化與觀測可靠性。  
  - 使用 **Leiden 社群偵測** 替代固定 K‑means，保證子圖聚類在大規模圖上具備自適應性與穩定性。  

- **實作層**  
  - `NoiseNet` 只需兩層 MLP，輸出方差估計，與主模型共享同一批次資料，額外計算成本低於 5%。  
  - 所有模組均以 **PyTorch Lightning** + **torch-geometric** 實作，支援單卡 24‑48 GB GPU 訓練，完整開源。  

- **應用層**  
  - 首次在 **動態化學合成流程**（ChemTS‑Dynamic）與 **自適應網路路由**（Routing‑Sim）兩個真實動態圖環境中驗證，展示跨領域可遷移性。  
  - 為 **Reward‑Free** 任務提供可直接遷移至有獎勵任務的策略初始化，縮短有獎勵微調的收斂時間。

**## 4. 實驗設計**  
- **資料集**

  - 《Graph Curiosity》NeurIPS 2025（單層資訊增益）  
  - 《Self‑Supervised World Models for Reward‑Free RL》ICLR 2026（無圖結構）  
  - 《Noise‑Aware Self‑Supervised World Models》ICLR 2026（僅噪聲加權）  
  - 隨機策略 + PPO（無內在獎勵）  

- **評估指標**

  - **樣本效率**：達到 80% 覆蓋率所需步數。  
  - **計算開銷**：每步 GPU 記憶體占用與 FLOPs。  

- **ablation study 設計**  
  - 移除 `Curiosity_Local`、僅保留 `Curiosity_Global`。  
  - 移除 `NoiseNet`（使用固定噪聲方差）。  
  - 替換 `Leiden` 為固定 K‑means，觀察聚類敏感度。  
  - 改變 `α,β,γ` 衰減速率，測試內在獎勵平衡對探索的影響。

**## 6. 風險與緩解**  
- **風險 1：子圖聚類在大圖上仍可能成為瓶頸**  
  - 緩解：採用 **mini‑batch Leiden** 與 **稀疏抽樣**，在每 10 步只更新一次聚類，減少計算頻率。  

- **風險 2：噪聲估計不準確導致探索信號失真**  
  - 緩解：加入 **噪聲正則化**（對 `σ²` 加上下界），並在訓練前使用少量標記噪聲的合成資料校准 `NoiseNet`。  

- **風險 3：內在獎勵過於複雜導致策略不穩定**  
  - 緩解：使用 **自適應衰減** 讓 `α,β,γ` 隨訓練進度自動調整，並在 PPO 中加入 **KL‑clip** 以限制策略變化幅度。  

此提案在技術可行性、創新性與資源可控性上均達到最佳平衡，值得在近期的研發計畫中優先執行。
