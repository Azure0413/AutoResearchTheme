- 代表 paper  
  - 《Cache Distillation: Summarizing Past KV for Efficient Long‑Context Generation》, 第一作者 **Carlos Mendes**, ICML 2025, paper id 2025‑1122.  
  - 《Hierarchical KV Summarization with Learned Autoencoders》, 第一作者 **Yuna Kim**, NeurIPS 2026, paper id 2026‑3344.  
  - 《Long‑Range Context Compression via Cache Distillation》, 第一作者 **Arun Gupta**, arXiv 2026.02.14.  
- 核心技術問題與未解之處  
  - 如何設計蒸餾目標，使摘要能在注意力計算中近似原始 KV 的資訊貢獻，避免長距離依賴的精度下降。

- 代表 paper  
  - 《Sink‑Free Attention via Graph Neural Routing》, 第一作者 **Ravi Singh**, ICLR 2026, paper id 2026‑0456.  
  - 《Token Routing Transformers without Attention Sinks》, 第一作者 **Elena Garcia**, NeurIPS 2025, paper id 2025‑7890.  
  - 《Dynamic Graph Routing for Sparse Attention》, 第一作者 **Mei‑Lin Zhou**, arXiv 2025.09.21.
