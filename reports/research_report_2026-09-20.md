**方案 1：Lie‑Algebra 參數化的譜分解卷積核 (Spectral‑Lie Conv)**  
- **核心 idea**：把連續群的 Lie‑algebra 係數直接映射到卷積核的譜空間，讓卷積在頻率層面天然等變，避免在空間層面做顯式指數映射的數值不穩。  
- **技術細節**  
  - **輸入**：物理場 `u(t,x)`、座標網格 `X`、可選的邊界條件向量。  
  - **模組設計**：  
    1. **Lie‑Encoder**：一個小型 MLP，輸入當前時間步的局部特徵，輸出 Lie‑algebra 基底的係數向量 `α∈ℝ^d`。  
    2. **譜投影層**：把 `α` 乘上一組預先固定的正交基 `Φ`（來自離散傅里葉或 Chebyshev 多項式），得到譜係數 `β = Φ·α`。  
    3. **Spectral‑Lie Conv**：在頻率域把 `β` 作為卷積核的幅度，對 `u` 做快速傅里葉變換、頻域乘法、逆變換，完成一次等變卷積。  
    4. **時間步迭代**：使用顯式歐拉或二階 Runge‑Kutta 進行時間前進。  
  - **訓練目標**：最小化場的 L2 重建誤差，同時加入 **譜正則**（限制高頻係數的 L2 範數）防止過擬合。  
  - **損失函數**：`L = L_MSE + λ_spec·∑_k |β_k|^2`。  
- **與 SOTA 的差異**  
  - **改動位置**：在 *Learning Continuous Symmetry Groups for PDEs*（NeurIPS 2025）中的第 4 行「生成群元素 → 指數映射」被 **改為第 4 行「生成譜係數 → 頻域卷積」**。  
  - **原因**：頻域卷積避免了指數映射的數值梯度爆炸，且譜係數直接控制不同頻率的對稱變換，提升了高頻模式的穩定性與精度。  
- **預期改善的指標與原因**  
  - **Benchmark**：Navier‑Stokes 渦旋流模擬（OpenFOAM‑Generated Turbulent Dataset, 2025）  
  - **指標**：相對 L2 錯誤下降 12% 以上，且在高雷諾數情況下能保持能量守恆誤差 < 1%。  
  - **因果鏈**：譜正則抑制高頻噪聲 → 頻域卷積保證等變性 → 數值梯度更平滑 → 時間積分誤差減少 → 整體誤差下降。  
- **最小可行實驗 (MVP)**  
  - **資料集**：2‑D 渦旋流 (Re=500) 的 CFD 數值解（約 10k 時間步）。  
  - **模型**：Lie‑Encoder 2 層 MLP（隱藏 64）+ 3 個 Spectral‑Lie Conv。  
  - **硬體**：單張 RTX‑3090 可在 4 小時內完成訓練，參數量 < 0.5 M。

**方案 2：曲率驅動的群導向自適應網格 (Curvature‑Guided Group‑Adaptive Mesh, CG‑GAM)**  
- **核心 idea**：利用局部幾何曲率與群不變誤差指標共同決定網格細化，讓網格資源自動集中在對稱破缺最嚴重的區域。  
- **技術細節**  
  - **輸入**：當前解場 `u(t,·)`、座標點集合 `X`、上一時間步的群參數 `g`.  
  - **模組設計**：  
    1. **曲率估計器**：基於離散二階導數計算每個單元的高斯曲率 `K`.  
    2. **群不變誤差測度**：把解場在隨機抽樣的群變換 `g_i` 下的差異 `Δ_i = ‖u - g_i·u‖` 平均得到 `E_sym`.  
    3. **細化決策函數**：`Score = |K|·E_sym`，對 Score 超過阈值的單元執行二次細化。  
    4. **等變卷積層**：在細化後的非結構化點雲上執行 *Adaptive‑Mesh Equivariant Operator*（AMEO）中的等變卷積。  
  - **訓練目標**：同時最小化場的重建誤差與 **網格成本正則**（細化單元比例）。  
  - **損失函數**：`L = L_MSE + λ_mesh·(∑_cells 1_{Score>τ})`.  
- **與 SOTA 的差異**  
  - **改動位置**：在 *Adaptive‑Mesh Equivariant Operator (AMEO)*（arXiv 2025.12.03）第 7 行「根據誤差梯度細化」被 **改為第 7 行「根據曲率×群誤差細化」**。  
  - **原因**：僅靠誤差梯度會在對稱保持良好但局部幾何複雜的區域忽略細化需求；加入曲率讓網格在幾何急變處也得到足夠解析度。  
- **預期改善的指標與原因**  
  - **Benchmark**：燃燒波前傳播（Combustion Front Dataset, ICLR 2026）  
  - **指標**：在相同參數量下，前緣位置的 L∞ 錯誤降低約 15%，且總單元數減少 20%。  
  - **因果鏈**：曲率捕捉幾何急變 → 群誤差捕捉對稱破缺 → 細化聚焦於兩者交集 → 高效分辨前緣 → 誤差顯著下降。  
- **最小可行實驗 (MVP)**  
  - **資料集**：2‑D 燃燒波前的高解析度模擬（約 5k 時間步）。  
  - **模型**：曲率估計器 2 層卷積、群誤差測度 3 個隨機抽樣、細化阈值手動調整。  
  - **硬體**：單張 RTX‑A6000，訓練 2 小時即可觀測到誤差與單元數的變化。

**方案 3：張量場守恆流的高階 SE(3) 等變圖訊息傳遞 (Tensor‑Conserved Flow GNN)**  
- **核心 idea**：在訊息傳遞過程中顯式保證能量、角動量的守恆，透過對稱的張量場流映射取代傳統的非保守聚合。  
- **技術細節**  
  - **輸入**：分子圖 `G(V,E)`（原子位置、原子類型、鍵類型）、初始能量向量 `E0`。  
  - **模組設計**：  
    1. **張量場初始化**：每個節點產生 2‑階張量 `T_v`（對稱矩陣）和標量能量 `e_v`，使用兩層 MLP。  
    2. **守恆流映射**：對每條邊 `(u,v)`，計算相對向量 `r_uv`，將 `T_u`、`T_v` 透過 *對稱外積* 與 `r_uv` 結合，得到流向 `F_uv`（保持 SE(3) 等變）。  
    3. **張量場更新**：節點張量更新規則 `T_v←T_v + Σ_{u∈N(v)} F_uv`，同時把流的散度作為能量變化 `Δe_v`，更新 `e_v←e_v+Δe_v`。  
    4. **反向投影**：在最後一層把張量場投影回原子坐標，輸出反應產物的幾何與能量。  
  - **訓練目標**：最小化產物結構的 RMSD 與真實能量的絕對差，同時加入 **守恆懲罰**（流的總散度必須等於零）。  
  - **損失函數**：`L = L_RMSD + λ_E·|E_pred - E_true| + λ_cons·|Σ_v div(T_v)|`.  
- **與 SOTA 的差異**  
  - **改動位置**：在 *Higher‑Order SE(3)‑Equivariant Transformers for Reaction Prediction*（ICML 2025）第 9 行「訊息聚合 = sum(MLP(message))」被 **改為第 9 行「訊息聚合 = 張量場守恆流」**。  
  - **原因**：傳統的加總聚合不保證物理守恆，會在長序列反應中累積能量漂移；守恆流直接在張量層面強制守恆，降低物理不一致性。  
- **預期改善的指標與原因**  
  - **Benchmark**：USPTO‑Reaction‑Energy (2025) 包含 50k 反應的能量與產物座標。  
  - **指標**：能量預測 MAE 從 0.42 kcal/mol 降至 0.28 kcal/mol，結構 RMSD 降低約 10%。  
  - **因果鏈**：守恆流保證能量守恆 → 預測的能量更可信 → 反應路徑的幾何更符合物理 → RMSD 與 MAE 同時下降。  
- **最小可行實驗 (MVP)**  
  - **資料集**：從 USPTO 中抽取 5k 個單步反應（含能量標籤）。  
  - **模型**：張量場初始化 64 維、守恆流更新 3 次迭代、總參數 0.8 M。  
  - **硬體**：單張 RTX‑3080，訓練 1 小時即可觀測 MAE 改善。

**方案 4：分層群參數共享的混合頻率‑空間等變算子 (Hybrid‑FreqSpace Equivariant Operator, HFS‑EO)**  
- **核心 idea**：在同一模型內同時使用空間卷積（局部細節）與頻率卷積（全局對稱），並在不同層級共享同一組 Lie‑group 參數，以減少參數冗餘與提升長程一致性。  
- **技術細節**  
  - **輸入**：時間依賴的場 `u(t,·)`、網格座標 `X`。  
  - **模組設計**：  
    1. **全局頻率模組**：對 `u` 進行快速傅里葉變換，使用一組由 **共享 Lie‑Encoder** 產生的譜係數 `β_g`（同方案 1 的 Lie‑Encoder），在頻率域做乘法，得到全局等變特徵 `û_g`.  
    2. **局部空間模組**：在原始網格上執行 *Equivariant Convolution*（使用相同的 Lie‑Encoder 輸出的群元素 `g` 作為卷積核的旋轉/尺度），產生局部特徵 `u_s`.  
    3. **特徵融合層**：把 `û_g` 逆變換回空間，與 `u_s` 做逐點加權求和（加權係數由另一小型 MLP 決定）。  
    4. **時間演進**：使用一階隱式歐拉，將融合後的特徵作為下個時間步的輸入。  
  - **訓練目標**：最小化場的 L1 損失，外加 **全局對稱一致性正則**（頻率特徵在不同群變換下保持不變）。  
  - **損失函數**：`L = L_L1 + λ_global·E_sym_freq`.  
- **與 SOTA 的差異**  
  - **改動位置**：在 *Symmetry‑Regularized Neural Operator (SNO)*（ICLR 2026）第 5 行「僅使用空間卷積」被 **改為第 5 行「空間卷積 + 頻率卷積 (共享 Lie‑Encoder)」**。  
  - **原因**：純空間卷積只能捕捉局部對稱，對於長程模式（如波動傳播）表現不足；加入頻率卷積提供全局等變性，且共享 Lie‑Encoder 減少參數重複，提升訓練效率。  
- **預期改善的指標與原因**  
  - **Benchmark**：海浪傳播 (DeepWave‑2025) 的長時段模擬（T=500 步）。  
  - **指標**：相對 L1 誤差下降 9%，且在 128‑GPU 分布式訓練下參數增幅僅 3%（比起純空間 SNO）。  
  - **因果鏈**：頻率卷積捕捉全局波形 → 空間卷積捕捉局部非線性 → 融合後解的波形相位與幅度更準確 → L1 誤差降低。  
- **最小可行實驗 (MVP)**  
  - **資料集**：1‑D 線性波方程的合成資料（10k 時間步、每步 256 點）。  
  - **模型**：Lie‑Encoder 1 層 32 隱藏、頻率卷積 2 層、空間卷積 2 層，總參數 < 0.4 M。  
  - **硬體**：單張 RTX‑2070 可在 30 分鐘內完成 5‑epoch 訓練，驗證 L1 誤差改進。
