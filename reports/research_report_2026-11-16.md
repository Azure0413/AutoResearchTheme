**## 1. 研究痛點與背景**  
- 大型語言模型在後訓練階段極易受到少量惡意資料的毒化，現有防禦多聚焦於**全模型再訓練**或**單次反事實微調**，無法在資源受限的環境下快速恢復模型性能。

**## 2. 核心研究方法**  
本研究提出 **因果圖增強式迭代修復＋稀疏遮罩 (CGAIR‑SCEM)**，核心概念是：先以激活捕捉生成**稀疏因果子圖**，再利用**圖正則化**指引**稀疏遮罩**只更新與高信度因果邊相關的參數，循環多次直至圖變化收斂。  

**演算法步驟**  
1. **激活捕捉**：在前向傳播時，使用 `torch.utils.checkpoint` 只保留關鍵層的激活向量 `A_l`。  
2. **稀疏因果圖學習** (`GraphLearner`)：  
   - 以增強版 PC‑algorithm 為基礎，結合 Gumbel‑Softmax 產生二元遮罩 `M`（稀疏度由 `τ` 控制）。  
   - 輸出稀疏圖 `G_t = (V, E_t, w_t)`，其中 `w_t` 為邊權重。  
3. **圖正則化** (`GraphReg`)：計算當前圖與前一輪圖的相似度 `sim(G_t, G_{t‑1})`，產生正則項 `graph_reg = 1 - sim`。  
4. **稀疏遮罩參數選擇** (`ParamSelector`)：僅保留與 `E_t` 相關的參數子集 `θ_masked = θ ⊙ M_param`。  
5. **反事實微調** (`CF‑FineTuner`)：在少量反事實樣本 `D_cf` 上，以交叉熵 `CE_clean` 為主損失，加入 `graph_reg` 與 L1 稀疏懲罰 `L1(M)`。  
6. **迭代更新**：重複步驟 1‑5，直至 `graph_reg < ε` 或達到最大迭代次數 `T`.  

**訓練目標**  
```
Loss = CE_clean
       + λ1 * graph_loss          (負對數圖匹配分數)
       + λ2 * graph_reg           (圖相似度正則)
       + λ3 * L1(M)               (稀疏遮罩 L1 懲罰)
```
超參數 `λ` 於驗證集上自適應調整。

**推論流程**  
- 給定疑似被毒化的模型與少量乾淨驗證樣本，直接執行 **一次** `GraphLearner` → `ParamSelector` → `CF‑FineTuner`，得到已修復的權重 `θ*`，不需要再跑完整的迭代過程。
